Customer
   ↓
index.html
   ↓
script.js
   ↓
POST /api/quotations
   ↓
Node.js / Express
   ↓
MySQL
   ↓
webvertex database
   ↓
quotations table

The data is saved with:

and MySQL automatically stores:

created_at

19. Common Problems
❌ Problem: npm start doesn't work

Make sure you are inside:

webvertex\backend

Check:

dir

You should see:

server.js
package.json
.env
node_modules

Then:

npm start
❌ Problem: Port 5000 already in use

You may already have another Node server running.

Press:

Ctrl + C

in the other backend terminal.

Then:

npm start
❌ Problem: MySQL connection failed

Check XAMPP:

MySQL → Running 🟢

Then check:

backend/.env

It should currently be:

DB_HOST=localhost
DB_USER=root
DB_PASSWORD=
DB_NAME=webvertex
DB_PORT=3306
❌ Problem: Quote says successful but database doesn't update

Check that:

Backend is running.
Database is running.
quotations table exists.
Browser console has no JavaScript errors.
The API is receiving the request.

Check phpMyAdmin:

webvertex → quotations → Browse
